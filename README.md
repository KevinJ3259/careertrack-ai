# CareerTrack AI

# Features

- 🔐 JWT Authentication
- 📋 Job Application Management
- 📊 Analytics Dashboard
- 📌 Kanban Workflow
- 🤖 AI Resume Optimizer
- ✍️ AI Cover Letter Generator
- 🎤 AI Interview Coach
- 💬 AI Career Assistant
- 📅 Reminder Management
- 📈 Resume Version Manager
- 🌙 Dark Mode
- ☁️ Cloud Deployment
